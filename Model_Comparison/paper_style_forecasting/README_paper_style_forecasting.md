# Paper-Style Forecasting Module

## 1. What this module does

This module replicates the retrospective forecasting logic from the hybrid-surrogate
reference study, using the **SBM-SIR simulator** to generate a synthetic epidemic
trajectory, and the **LSTM surrogate** to forecast its hidden future segment.

> This module does not forecast the real SPB 2022 observations. Instead, it
> reproduces the paper-style experimental protocol by generating a synthetic
> target trajectory with the SBM-SIR simulator and testing whether the LSTM
> surrogate can recover the hidden future segment.

---

## 2. Difference from previous experiments

| Experiment | Target curve |
|---|---|
| `forecasting/` (Exp. 1) | Real SPB 2022 confirmed cases |
| `forecasting/` (Exp. 2) | LSTM-fitted smoothed curve |
| **`paper_style_forecasting/`** (Exp. 3) | **Synthetic SBM-SIR trajectory** |

---

## 3. What "SBM-SIR target" means

The target curve is generated by running the full mechanistic SBM-SIR model
with fixed parameters (`beta_network=0.2436`, `beta_household=2.544`,
`delta=1.0552`, `fermi_mu=19.2075`) for 100 Monte Carlo replicas and averaging.
This produces a smooth, noise-free epidemic curve that serves as ground truth.

---

## 4. What "surrogate forecast" means

The LSTM surrogate is a neural network trained to approximate the SBM-SIR
output for any parameter vector `theta`. During calibration, `theta` is
searched to minimise the RMSE between the surrogate output and the **known**
portion of the target curve. The calibrated surrogate then generates
forecast trajectories for the next 14 days.

---

## 5. How to run

```bash
# From Model_Comparison/ directory:
python3 paper_style_forecasting/paper_style_forecast.py

# Or generate the target curve only:
python3 paper_style_forecasting/generate_sbm_target.py
```

Edit `paper_style_utils.py` to switch modes:

```python
MODE = "surrogate"   # fast — LSTM surrogate
MODE = "sbm"         # slow — direct SBM-SIR
```

All outputs are written to `paper_style_forecasting/output/`:

| File | Description |

| `sbm_synthetic_target.csv` | Full synthetic target curve (fraction + cases) |

| `forecast_tpeak_minus_7.png` | Individual scenario figure (t_peak − 7) |
| `forecast_tpeak_plus_7.png` | Individual scenario figure (t_peak + 7) |

| `posterior_parameters_tpeak_minus_14.csv` | Top-k accepted parameters |
| `posterior_parameters_tpeak_minus_7.csv` | Top-k accepted parameters |
| `posterior_parameters_tpeak_plus_7.csv` | Top-k accepted parameters |
| `forecast_trajectories.csv` | All forecast trajectory values |
| `forecast_metrics.csv` | Evaluation metrics per scenario |
| `paper_style_forecast_summary.md` | Auto-generated summary |

## 7. Scenarios

| Scenario | Cut at | Meaning |
|---|---|---|
| `tpeak_minus_14` | t_peak − 14 | Only growth phase visible; hardest forecast |
| `tpeak_minus_7` | t_peak − 7 | Near-peak; most growth visible |
| `tpeak_plus_7` | t_peak + 7 | Post-peak; tests decline-phase recovery |

---

## 8. Thesis paragraph

> "To reproduce the experimental logic of the reference hybrid-surrogate study,
> the proposed SBM-SIR model was first used to generate a synthetic epidemic
> trajectory. This trajectory was treated as the baseline target curve.
> Forecasting was then performed by revealing only the initial segment of the
> curve and hiding the following 14 days. Three forecast origins were considered:
> 14 days before the peak, 7 days before the peak, and 7 days after the peak.
> For each scenario, the LSTM surrogate was calibrated only on the known segment
> and then used to generate posterior-like forecast trajectories and uncertainty
> intervals. The hidden SBM-SIR segment was used exclusively for evaluation."
